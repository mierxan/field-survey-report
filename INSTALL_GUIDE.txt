INSTALL THE FIELD SURVEY REPORT ON ANOTHER PC / LAPTOP  (Windows)
================================================================

A. ON THE NEW PC (once)
 1. Install Python 3.14 or newer from python.org.
    Tick "Add python.exe to PATH" on the first screen.
 2. Copy this whole folder to the new PC (for example to C:\FieldSurveyReport).
    Do NOT copy the .venv folder, users.json, settings.json,
    Field_Survey_Reports.xlsx or the Report Forms folder from the old PC
    unless you want the same data there.
 3. Double-click  SETUP_NEW_PC.bat  (needs internet, takes a few minutes).
 4. Double-click  START_FSR.bat  to open the program.
    Sign in with the Owner initials MPR, or sign up and wait for approval.
 5. PDF / Print needs Microsoft Excel or LibreOffice on that PC.

B. HOW THE DATA IS STORED (Owner and User editions)
 There is no shared or online database. The installers are the normal way to
 set up a PC (see BUILD_INSTALLER.txt):
   * Site PCs: the User edition. Reports stay in that PC's Excel and JSON files;
     MySQL is never used. Export Master Data writes one file for the owner.
   * The owner's PC: the Owner edition. Excel + MySQL on that same PC (MySQL
     Workbench to look at it). Import Master Data brings in the files from
     every site PC and every phone.
 Run from this folder (START_FSR.bat), the program is the Owner edition; for a
 site PC set  FSR_EDITION=user  or use the User installer.

 MySQL accepts connections from the owner's PC only: my.ini has
   bind-address=127.0.0.1   (set 2026-11-09; the backup of the earlier file is
   my.ini.before_bind_127_20261109 in C:\ProgramData\MySQL\MySQL Server 8.0)
 Other PCs never connect to it. The earlier "Option 2" (all PCs sharing one
 MySQL over the network) is retired; do not open port 3306 in the firewall.

C. UPDATING LATER
 Replace field_survey_report.py (and the other .py files) in the folder.
 Do not delete settings.json, users.json, db_config.json or the Excel file.
