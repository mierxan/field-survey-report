INSTALL THE FIELD SURVEY REPORT ON ANOTHER PC / LAPTOP  (Windows)
================================================================

A. ON THE NEW PC (once)
 1. Install Python 3.12 or newer from python.org.
    Tick "Add python.exe to PATH" on the first screen.
 2. Copy this whole folder to the new PC (for example to C:\FieldSurveyReport).
    Do NOT copy the .venv folder, users.json, settings.json,
    Field_Survey_Reports.xlsx or the Report Forms folder from the old PC
    unless you want the same data there.
 3. Double-click  SETUP_NEW_PC.bat  (needs internet, takes a few minutes).
 4. Double-click  START_FSR.bat  to open the program.
    Sign in with the Owner initials MPR, or sign up and wait for approval.
 5. PDF / Print needs Microsoft Excel or LibreOffice on that PC.

B. CHOOSE HOW THE PC STORES DATA
 Option 1 - separate PC (simplest): each PC keeps its own Excel file, its own
   users and its own reports. In db_config.json set  "enabled": false
   (or delete db_config.json). Nothing else is needed.

 Option 2 - all PCs share ONE MySQL database (reports are saved to the same
   place; every PC can open every report):
   1. Pick the PC that has MySQL ("the server PC"). Find its address:
      open Command Prompt there and type  ipconfig  (IPv4 Address, e.g. 192.168.1.20).
      Give that PC a fixed IP (router setting) so the address does not change.
   2. On the server PC, MySQL Workbench > root > run  allow_network_access.sql
   3. On the server PC allow port 3306 in Windows Firewall:
      Windows Defender Firewall > Advanced settings > Inbound Rules > New Rule
      > Port > TCP 3306 > Allow the connection > name it "MySQL".
   4. Make sure MySQL listens on the network: in my.ini (C:\ProgramData\MySQL\
      MySQL Server 8.0) the line  bind-address  must not be 127.0.0.1
      (remove it or use 0.0.0.0), then restart the MySQL80 service.
   5. On each other PC edit db_config.json:
        "host": "192.168.1.20"      <- the server PC's address
      then open the program: the three circles show the colours when it works.
   Note: sign in accounts (users.json) are still kept on each PC separately.
   Excel files stay on each PC; the shared copy of every report is in MySQL.

C. UPDATING LATER
 Replace field_survey_report.py (and the other .py files) in the folder.
 Do not delete settings.json, users.json, db_config.json or the Excel file.
